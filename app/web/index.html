    03 / Engineering, in the open
    The guarantees.
    And the receipts.
    Read the implementation ↗
    
      
    01
    One ID. One enqueue.
    A Redis Lua script claims the event ID and queues the job atomically. Concurrent duplicates cannot create extra jobs within the idempotency window.
    02
    Failure has a path.
    Failed attempts persist before acknowledgement. Exponential backoff with jitter leads to another attempt; exhausted jobs go to the dead-letter queue.
    03
    Crashes don’t erase work.
    A healthy worker reclaims stale, unacknowledged messages. Outbound HMAC signs the exact bytes sent to the receiver.
